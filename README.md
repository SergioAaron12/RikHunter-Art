# RikHunter Art

Portafolio web para artista visual. Incluye página principal, galería de clientes y sección sobre mí. Estructura lista para personalización y despliegue.

## Estructura inicial
- index.html (Inicio)
- cliente.html (Galería Cliente Feliz)
- mi.html (Sobre Mí)
- styles.css (estilos globales)
- stylescliente.css (estilos galería)
- stylemi.css (estilos sobre mí)
- main.js (funcionalidad JS)
- asset/ (carpeta para imágenes y recursos)

## Uso
Abre index.html en tu navegador para ver el sitio. Personaliza los archivos según tus necesidades artísticas.
